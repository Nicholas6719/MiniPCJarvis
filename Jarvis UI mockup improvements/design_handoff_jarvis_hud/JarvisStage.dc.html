Building with the Vulkan backend docs / build.md

Vulkan is the recommended backend for integrated graphics. Build with the flag enabled, then set the number of layers to offload based on available shared memory.

cmake -B build -DGGML_VULKAN=ON
cmake --build build --config Release
// then
llama-server -m model.gguf -ngl 33

Offloading more layers than fit in shared memory will silently fall back to host memory and cost you throughput.

Picking a layer count

Start high and walk it down until the load stops spilling. On a 32 GB machine with half allocated to the iGPU, 33 is usually the ceiling for a 7B model at Q4.

// check what actually landed on the GPU
llama-server -m model.gguf -ngl 33 --verbose
// look for: offloaded 33/33 layers to GPU
